# SPINE-TRACT Shiny App

SPINE-TRACT is a Shiny app template for the Spine Trauma Resource and Acute Care Trajectory calculator. It mirrors the deployment structure used for the TQIP TBI calculator while swapping in the spine endpoints and spine-facing interpretation language.

## Expected folder structure

```text
spine_tract_app/
├── app.R
├── manifest.json                  # optional; generated by rsconnect/writeManifest
├── data/
│   ├── model_bundle.rds            # required; upload locally before testing/deploying
│   └── predictor_metadata.rds       # required; upload locally before testing/deploying
└── www/
    └── ohsu_logo.png               # optional
```

## Required files

Place these files in `spine_tract_app/data/`:

```text
model_bundle.rds
predictor_metadata.rds
```

The app is metadata-driven and expects the model bundle generated from the locked SPINE-TRACT pipeline. It looks for endpoints with names similar to:

```text
discharge
icu_admission
mechanical_ventilation
hlos_ge20
icu_los_ge8
vent_days_ge8 or vent_days_ge8_full
operative_spine_intervention
```

## Local test

From RStudio:

```r
setwd("spine_tract_app")
shiny::runApp()
```

Or from the parent repository:

```r
shiny::runApp("spine_tract_app")
```

## shinyapps.io deployment

After local testing:

```r
install.packages("rsconnect")
rsconnect::setAccountInfo(
  name = "YOUR_SHINYAPPS_ACCOUNT",
  token = "YOUR_TOKEN",
  secret = "YOUR_SECRET"
)

rsconnect::deployApp(
  appDir = "spine_tract_app",
  appName = "spine-tract",
  appTitle = "SPINE-TRACT"
)
```

If you already have a working `manifest.json`, place it next to `app.R` before deployment.

## Interpretation language

The app intentionally labels outputs as resource-utilization trajectories. ICU admission, mechanical ventilation, prolonged hospital/ICU/ventilator utilization, and operative spine intervention reflect observed resource use or procedure receipt, not treatment indication, appropriateness, or unmet need.
