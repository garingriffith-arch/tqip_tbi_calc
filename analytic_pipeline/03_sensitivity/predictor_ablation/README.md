# Classification predictor-family ablation

The original R source file for this analysis was not retained in the archived analysis project. To avoid introducing unverifiable reconstructed code, no replacement source file is presented.

The complete manuscript-facing output set from the analysis is preserved under `results/`. It includes the temporal fold definitions, candidate ablation definitions, selected reference architectures, run-level QC, class-level performance metrics, metric deltas, and temporal summaries used in the manuscript supplement and predictor-ablation figure.

`09_duration_predictor_ablation.R` uses the selected reference-architecture output from this directory when reproducing the duration-model ablation analysis.
